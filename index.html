Run locally (2–3 minutes)

Requires JDK 21, Maven, and Docker (or a local MySQL 8 instance).

1
Clone the repository 
git clone https://github.com/aayushbodh726-sketch/campuspulse-ai-java.git
cd campuspulse-ai-java
2
Start MySQL with Docker 
docker compose up -d mysql
3
Run the application 
mvn spring-boot:run

Then open http://localhost:8080
